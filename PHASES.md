# Project phases and status

Standard shape: see the workspace `docs/phases.md`. Status: **planned, nothing started; this project begins only after Projects 1 and 2 have results.** It is an independent, personally owned build using no employer hardware, code, designs, data or documents.

| Phase | Content | Status |
|---|---|---|
| 0. Scope and protocol | Question (does camera plus range sensing beat camera-only for obstacle avoidance and target localisation); safety rules; course and trial counts fixed in advance | planned |
| 1. Setup and budget | Verified bill of materials and wiring diagram; budget checked before buying, bought in stages | planned |
| 2. Pipeline and validation | Interfaces proven in simulation first; safe power and emergency stop; teleoperation; odometry calibration | planned |
| 3. Baseline | Camera-only perception with latency logging, repeatable indoor course, low speed | planned |
| 4. Intervention | Add range sensing; camera-only versus camera plus range, fixed trial counts, collisions and emergency stops logged | planned |
| 5. Diagnosis and iteration | Failure analysis of perception and navigation | planned |
| 6. Extension | Optional thermal sensing, only after the simulated study in Project 2; never any alive/dead claim | planned |
| 7. Report and release | Report, safety checklist, logs, demo video including failures, two-page summary | planned |

Safety rules for every phase: low speed, controlled indoor space, wheels raised at first power-up, no automatic driving toward people, consenting participants only.
